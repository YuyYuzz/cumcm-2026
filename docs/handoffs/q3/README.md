## 模型与求解过程

研究区域为半径 0.02 m、长度 0.25 m 的轴对称长圆柱，只考虑径向传热传质。问题三从 $T=28\ ^\circ\mathrm C$、$C=2.55\ \mathrm{kg/kg}$ 的均匀初值重新计算，不续接问题二终值。

模型严格复用附录3的 $\rho(C)$、$c_p(C)$、$k(C)$ 与 $D(C,T)$，其中 Arrhenius 指数使用 $T+273.15$ K。外表面继续使用 $h=25\ \mathrm{W/(m^2\cdot K)}$ 与 $h_m=8\times10^{-7}\ \mathrm{m/s}$；这是附录3未重新给出边界系数时沿用问题一、问题二条件的补充假设。

正式程序将温度和水分组成同一 $2N$ 维状态，采用单元中心圆柱径向守恒有限体积法和 BDF 同步积分。内部变系数采用调和平均，真实表面状态由半网格传递关系与 Robin 条件联合重构。判停量同时覆盖轴线、全部控制体中心及真实表面，不预设最大水分浓度的位置。

完整模型口径见 `docs/handoffs/q3/model_spec_q3.md`，详细计算与验证数字见 `docs/handoffs/q3/q3_results.md`。

## 局限与待确认事项

正式基准情景已经通过问题二对齐、网格加密、BDF 容差、`max_step`、瞬时与累计积分平衡、有限值、正水分浓度及终点全域阈值检查，可以作为问题三主结果冻结。

4 h 后环境冻结属于题面数据终止后的补充假设。高湿情景 $C_a=0.07$ 得到结束时间约 57.81 h，比基准延长约 0.63 h。低湿情景 $C_a=0.03$ 下，半网格 Robin 边界离散与强退化的 $D(C)$ 共同导致离散非线性表面方程出现多根及根分支折叠，且折叠位置随界面平均方式和空间网格变化。因此该情景不报告唯一精确结束时间，也不将其解释为真实干壳或物理系统多根，只作为边界条件与离散形式敏感性的模型局限。该局限不影响正式基准结果。

早期水分场接近均匀时，最大值在数值精度内形成近轴线平台，保存点的 `argmax` 偶尔落在非常靠近轴线的位置；终点高分辨率重构的唯一最大值位于轴线。这不影响全域判停，因为事件始终检查全部空间状态。

累计平衡由 60 s 保存点作梯形积分。终点累计相对残差为温度 $3.52\times10^{-6}$、水分 $9.34\times10^{-5}$；全时段最大相对残差出现在最早的 60 s，由粗时间采样下很小累计量作分母造成，应与终点累计残差分开解释。
