# A 题问题 1 独立模型规格

本文件用于不依赖任何源码的独立复现。证据来源只采用 A 题正式题面、附录 2 和附件 1；未引入参考文献中的替代公式或额外物理参数。

## 1. 几何、变量与假设

- 药材视为半径 `R=0.02 m`、长度 `L=0.25 m` 的圆柱。
- 仅研究径向 `r∈[0,R]`，忽略轴向与周向变化。
- `T(r,t)`、`Ta(t)` 和 `Ts(t)` 均表示摄氏温度，单位为 °C；若后续经验公式需要绝对温度，单独定义 `T_K=T+273.15`。
- 药材近似为长圆柱，仅描述径向过程；忽略周向和轴向变化，因此不能刻画靠近两端端面的局部轴向效应。
- `C(r,t)` 为题目定义的干基含水率，单位为 kg/kg。
- Q1 中温度场和含水率场解耦。不加入蒸发潜热、吸附等温线、Soret/Dufour 效应或收缩。

## 2. 控制方程

温度：

```text
rho*cp*∂T/∂t = (1/r) ∂/∂r (r*k*∂T/∂r)
```

水分：

```text
∂C/∂t = (1/r) ∂/∂r [r*D(C)*∂C/∂r]
D(C) = 7e-9*exp(-0.89/C)  (m²/s)
```

水分方程必须保持变系数守恒通量形式，不能改写成 `D(C)` 乘以常系数拉普拉斯算子。

## 3. 初始条件

对所有 `0≤r≤R`：

```text
T(r,0)=28 °C
C(r,0)=2.55 kg/kg
```

## 4. 边界条件与符号

`r` 的正方向由圆柱轴线指向表面。在 `r=0` 使用轴对称零通量：

```text
∂T/∂r(0,t)=0
∂C/∂r(0,t)=0
```

在 `r=R` 采用本文建立的第三类对流边界：

```text
-k*∂T/∂r(R,t) = h*[T(R,t)-Ta(t)]
-D(C)*∂C/∂r(R,t) = hm*[C(R,t)-Ca(t)]
```

其中 `Ta(t)`、`Ca(t)` 分别为附件 1 的烘房温度和水分浓度。

## 5. 参数

| 参数 | 数值 | 单位 |
|---|---:|---|
| `R` | 0.02 | m |
| `L` | 0.25 | m |
| `rho` | 820 | kg/m³ |
| `cp` | 2600 | J/(kg·K) |
| `k` | 0.36 | W/(m·K) |
| `h` | 25 | W/(m²·K) |
| `hm` | 8×10⁻⁷ | m/s |

`L` 不进入一维局部 PDE，但在全圆柱能量/水分积分平衡核验中使用。

## 6. 附件 1 插值规则

只读取附件 1 中 `t=0,60,…,1800 s` 的 31 行。三列必须依次为“时间”“温度”“水分浓度”，且不得存在空值或非有限值。在每两个相邻实测时刻之间分别对 `Ta` 和 `Ca` 作分段线性插值；不平滑、不外推、不使用 1800 s 以后的记录。

## 7. 主数值离散

- 将 `[0,R]` 均匀划分为 `N` 个环形控制体。面坐标为 `r_j=jR/N`，单元中心为 `(r_j+r_{j+1})/2`。
- 单位周向、单位长度下第 `i` 个控制体几何权重为 `V_i=(r_{i+1/2}²-r_{i-1/2}²)/2`。
- 面通量统一定义为 `F_T=k*T_r`、`F_C=D*C_r`。离散散度为：

```text
[r_(i+1/2)*F_(i+1/2)-r_(i-1/2)*F_(i-1/2)] / V_i
```

- 中心面 `r=0` 的通量严格设为零。
- 温度内部面因 `k` 为常数，使用相邻单元中心差分。
- 水分内部面的扩散率取相邻单元 `D(C)` 的调和平均，左右控制体共享完全相同、符号相反的界面通量。
- 外表面距最外单元中心半个网格。温度表面值由半网格导热关系与 Robin 条件联立解析求出。
- 水分表面值 `Cs` 位于最外单元中心值与 `Ca` 之间，通过下式的一维标量根求解得到；半网格扩散率是单元中心和表面 `D` 的调和平均：

```text
D_face(Cs)*(Cs-C_last)/(Δr/2) + hm*(Cs-Ca) = 0
```

由于题给 `D(C)` 在低含水率处迅速趋近于零，该非线性半网格方程可能另有一个靠近 `Ca` 的退化数学根。数值上从最外单元值连续向 `Ca` 搜索，选取遇到的第一个根；该物理支路满足网格细化时 `Cs→C_last`，不选择低扩散率导致的伪支路。

- 半离散常微分方程使用 `scipy.integrate.solve_ivp(method="BDF")`。本文设置多级网格进行加密检验；测试发现初边界不相容在 `t=1 s、r=R` 形成极薄瞬态层，因此继续细化至 `N=321、641、1281、2561`。正式输出使用 `N=2561`、`rtol=1e-8`、温度 `atol=1e-10`、水分 `atol=1e-11`、`max_step=5 s`，内部状态输出为 `t=0,1,…,1800 s`；正式 `result1.xlsx` 按题面模板从 `t=1 s` 到 `1800 s`。

## 8. 输出重构

- 计算网格与题目要求的 21 个输出位置分离。
- 轴线值利用对称性作关于 `r²` 的两点线性外推；表面值由 Robin 半网格关系得到。
- 将轴线、全部单元中心及表面值组成径向节点，使用保形分段三次插值（PCHIP）输出 `r=0,0.001,…,0.020 m`。
- `t=0` 一行严格按题给初值在包括表面的全部位置写为 `T=28、C=2.55`。初值的零梯度与 `t=0` Robin 条件在角点不相容，Robin 条件用于决定 `t>0` 的演化，不反向修改题给初值。
- `result1.xlsx` 必须且仅包含“温度”“水分浓度”两个工作表。A 列为 `0…1800 s`，第一行为 `0…2 cm`、步长 `0.1 cm`，数值显示四位小数。
- 论文表 1/表 2 取时刻 `100、300、600、900、1200、1500、1800 s`，位置 `0、0.5、1.0、1.5、2.0 cm`。

## 9. 验证要求

1. 比较 `N=41、81、161` 在完整 1 s×0.1 cm 输出网格和论文表格点上的差异。
2. 在正式 `N=2561` 网格上收紧为 `rtol=1e-10`、温度 `atol=1e-12`、水分 `atol=1e-13`、`max_step=2 s`。
3. 核验控制体求和后的瞬时平衡和边界通量一致；再以 1 s 输出作梯形积分，核验累计能量/水分变化与累计表面通量一致。
4. 检查 NaN、负含水率、明显空间锯齿或时间振荡，并检查温度和含水率是否落在该抛物型问题的输入极值范围内。
