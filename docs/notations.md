# A题统一符号表

本文件维护论文的符号定义；排版版本位于 `contents/sections/04_symbols.tex`。当前收录已有材料中的主要物理量和数值离散符号，后续随各问建模进展增补。新增符号或调整定义时，同步更新这两个文件。

## 统一约定

- 原题符号优先，同一符号全文只表示一个物理量。下标 \(a\)、\(s\)、\(0\) 分别表示烘房空气、药材表面和初始状态；下标 \(i\) 表示离散控制体或节点编号。
- 正文中的 \(T,T_a,T_s\) 统一表示摄氏温度，单位为 ℃。凡进入 Arrhenius 经验公式时，单独定义绝对温度 \(T_K=T+273.15\)，并以 \(T_K\) 代入指数项；Q2、Q3、Q4 均遵循此规则，禁止将摄氏温度直接代入 Arrhenius 指数。
- 空间变量以m、时间变量以s定义；结果图表按题意显示cm或h时，只转换数值与单位，不重新定义符号。
- \(C\) 指药材干基含水率。\(C_a\) 采用附件给出的烘房空气水分浓度口径，不将其称为药材干基含水率。两者在边界模型中的关系由相应章节说明。
- \(R\) 始终表示药材半径。固定尺寸问题中视为常量，考虑尺寸变化时写为 \(R(t)\)，初始半径记为 \(R_0\)。本表不预设半径变化规律或长度是否变化。
- 表面量满足 \(T_s(t)=T(R,t)\)、\(C_s(t)=C(R,t)\)；尺寸变化时，将右端的 \(R\) 换为 \(R(t)\)。初始状态可用 \(T_0,C_0\) 等表示。

## 物理模型符号

| 符号 | 含义 | 单位 |
|---|---|---|
| \(t\) | 烘干时间 | s |
| \(t_e\) | 全域最大水分浓度首次降至阈值的临界时刻 | s |
| \(\xi\) | 材料坐标，\(\xi=r/R(t)\) | 1 |
| \(C_{\max}\) | 全域最大水分浓度 | kg/kg |
| \(r\) | 到圆柱中心轴的径向距离 | m |
| \(R\) | 药材半径；尺寸变化时记为 \(R(t)\) | m |
| \(L\) | 药材长度 | m |
| \(T\) | 药材温度，正文采用摄氏温度 | ℃ |
| \(C\) | 药材水分浓度，即干基含水率 | kg/kg |
| \(\rho\) | 药材密度 | kg/m³ |
| \(c_p\) | 药材比热容 | J/(kg·K) |
| \(k\) | 热传导系数 | W/(m·K) |
| \(D\) | 水分扩散系数 | m²/s |
| \(h\) | 对流换热系数 | W/(m²·K) |
| \(h_m\) | 对流传质系数 | m/s |
| \(T_a\) | 烘房空气温度，正文采用摄氏温度 | ℃ |
| \(C_a\) | 烘房空气水分浓度，采用附件口径 | kg/kg |
| \(T_s\) | 药材表面温度，正文采用摄氏温度 | ℃ |
| \(C_s\) | 药材表面水分浓度，即表面干基含水率 | kg/kg |
| \(\alpha\) | 热扩散率，\(\alpha=k/(\rho c_p)\) | m²/s |
| \(\tau_T\) | 径向热扩散特征时间 | s |
| \(\tau_C\) | 径向水分扩散特征时间 | s |

\(\rho,c_p,k,D\) 是否为常量及其具体经验关系，分别由各问的题给参数和模型说明确定。特征时间采用的参考半径、参考物性或参考含水率也在使用处给出，避免把Q1的参考取值直接推广到后续问题。

## 数值离散符号

| 符号 | 含义 | 单位 |
|---|---|---|
| \(N\) | 径向控制体总数 | 1 |
| \(\Delta r\) | 均匀径向网格宽度 | m |
| \(i\) | 控制体或节点编号 | 1 |

单位“1”表示无量纲。具体索引起点、取值范围及控制体面的位置在离散公式首次出现时说明。程序数组名、求解器内部参数及只用于实现的临时变量不列入论文总符号表。

## 后续增补方法

1. 先检查已有符号能否复用；同一物理量只因边界、初始状态或题问不同，不另起新符号。
2. 新增项目写清符号、含义、单位和适用范围，并在正文首次使用时解释。坐标变换、收缩速率等符号在实际采用相应模型后再加入，不预留无定义的空行。
3. 在本文件对应组中增补，并同步更新论文符号表。论文采用可跨页表格，新增条目时保留表头与续表结构，沿用现有模板样式。
4. 符号变更时检索正文、图表标题、结果报告和模型规格中的旧写法，按实际整合范围统一更新，随后编译检查。

## 来源与当前整合范围

本版以会话提供的 `notations.md` 为基础，对照原题附录2至4及Q1交付材料核对符号与单位。与附件版本相比，主要修订为统一正文摄氏温标并单独定义 Arrhenius 用的绝对温度、明确空气与药材水分浓度口径、说明时变半径和后续增补方式。

Q1 现有温度方程只涉及温差，采用摄氏温度不改变既有输出表值；后续含 Arrhenius 经验公式的问题均通过显式的 \(T_K\) 完成温标转换。
