## 需要在写作前处理的问题

### 1. 独立交叉验证的原始证据缺失

`README.md`、`q4_results.md` 和 `Q4_REVISION_LOG.md` 多次引用以下文件：

- `q4_phase1_report.md`；
- `q4_phase2_report.md`；
- `q4_phase1_results.json`；
- `q4_phase2_compare.json`。

这四个文件不在 `Q4.zip` 中，也不在当前仓库中。现有 `q4_results.md` 包含独立方法的终止时间和逐点差异数字，但这些数字目前不能由归档材料独立追溯。Q4 主程序自身的网格、容差、步长、根审计和工作簿验收仍可作为正式数值证据；论文若要写独立交叉验证的定量差异，应先补齐上述四个文件，否则应收紧为“交接材料报告了独立复核，原始对拍记录待补”。

### 2. 累计积分残差的表述必须区分终点值和全时段最大值

正式结果的终点累计相对残差为约 `2.02×10^-4`，满足当前验收阈值；但验证 JSON 中按 60 s 粗采样计算的 `max_relative_residual_after_60s` 为 `3.77×10^-2`，主要受早期累计量很小的分母影响。正文不能写成“全时段累计残差均不超过 `10^-3`”，应明确写“终点累计残差约为 `2.02×10^-4`，早期相对比值受小分母影响”。

### 3. Q4 正式模型假设需在正文明确标注

以下内容属于本文补充的建模假设，不能写成题目直接给定：

- 附件2只给半径，因此假设轴向长度保持 `25 cm`，仅发生径向收缩；
- `14400 s` 后环境温度和水分浓度保持附件1末值；
- 附录4未给新边界传递系数，因此沿用问题一至三的 `h` 和 `h_m`；
- 不显式加入蒸发潜热；
- 材料坐标中不额外加入收缩对流项；
- 固定物理位置越出当前移动表面时，结果表留空，表面列单独记录实时表面值。

### 4. 当前环境未完成完整重跑

本轮完成了 Python 静态编译检查，代码可通过 `py_compile`；但当前会话 Python 环境缺少 `SciPy` 和 `openpyxl`，没有重新运行 Q4 主程序、验证程序或工作簿导出链。因此本报告确认的是交付材料内部一致性和静态可执行性，不把本轮称为独立复现通过。交接说明中给出的 Python、NumPy、SciPy、openpyxl 和 Matplotlib 版本仍需在具备依赖的环境中复跑确认。

Q4 的主结果、工作簿、图件、模型规格和主程序材料已经完成归档，主程序内部数值验收通过，可以作为 Q4 正式写作的基础。当前唯一影响独立验证可追溯性的实质缺口，是交接说明引用但压缩包未提供的四个 Phase 1/Phase 2 原始交叉验证文件；在补齐前，Q4 正文应避免把独立方法的具体对拍数字写成已完整入库的证据。
