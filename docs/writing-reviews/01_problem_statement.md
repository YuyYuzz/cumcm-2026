## 写作前规划

本章回答“研究什么对象、依据哪些已知条件、四个问题分别要求什么”。论证链为：热风烘干的实际需求 → 药材初始状态与题给资料 → 预热阶段描述 → 全程变参数描述 → 全域含水率达标判定 → 考虑半径收缩后重新确定时长 → 统一结果输出要求。

段落职责：背景首段交代目的；第二段集中交代对象、初始条件和资料；四个问题各占一段，分别写输入、相对前问的变化和输出；末段合并精度与完整结果的采样要求。本章无需公式、图表或计算结果，不提前决定维度化简、边界外推、数值算法或收缩机制。
