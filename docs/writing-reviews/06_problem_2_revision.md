## 论证链与图表分工

继承问题一的径向几何及边界 → 引入含水率相关物性和温度相关扩散系数 → 同步求解 → 指定时刻/位置的两张结果表 → 径向分布及时间尺度解释 → 扩散系数变化及耦合机制解释 → 网格、容差和积分平衡检验 → 结论及适用范围。

两张结果表承担精确取值；径向剖面图承担空间分布比较；扩散系数图承担耦合机制解释。轴线—表面历程图与前述结果重复较多，本轮取消其正文调用，保留源图。单位保留在图内坐标轴及表的简短单位标识中，删除题注中的“横坐标为”“单位为”等解释句。

图片采用局部 minipage 与 captionof，将首次引用、图片和题注绑定为同一不可拆分排版块；表格按源文件顺序定位。未修改模板的字体、字号、页边距或全局浮动体参数。
