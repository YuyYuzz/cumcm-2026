## 必须在正文中保持的口径

- Q3 从题目初始状态重新计算，不接续 Q2 的终态；Q2 只用于前三小时逐点一致性检查。
- $0$--$14400\,\mathrm{s}$ 的附件 1 环境数据采用分段线性插值；$14400\,\mathrm{s}$ 后将附件末值 $T_a=50.165\,{}^\circ\mathrm{C}$、$C_a=0.04986\,\mathrm{kg/kg}$ 保持不变。这是题目数据终止后的补充边界假设。
- 终止事件检查轴线、全部控制体中心和真实表面，不预设全域最大值必在轴线；终点高分辨率复核才给出轴线位置。
- 网格加密用于离散稳定性，BDF 容差与内部步长用于时间积分稳定性，瞬时和累计积分用于通量一致性。它们不能替代实验验证。
- 终点累计相对残差为温度 $3.52\times10^{-6}$、水分 $9.34\times10^{-5}$。早期 $60\,\mathrm{s}$ 采样下的较大相对误差不能与终点残差混写。
- 不应声称水分浓度全程按相同速率下降；低含水率阶段扩散系数中的含水率因子会改变后期时间尺度。

## 审计发现与写作阻塞项

### A1：低湿敏感性存在离散边界根分支问题

在 $t>14400\,\mathrm{s}$ 将环境含水率改为 $C_a=0.03\,\mathrm{kg/kg}$ 时，半网格 Robin 边界离散与强退化的扩散系数共同导致离散非线性表面方程出现多根及根分支折叠，且折叠位置随界面平均方式和空间网格变化。因此不能报告低湿情景的唯一精确终止时间，也不能把该现象解释为真实干壳或物理系统多根。正式 Q3 论文只保留基准情景和高湿 $C_a=0.07$ 情景的数值结论；低湿情景作为边界与离散敏感性局限。

### A2：绘图链已补齐并完成复核

已补入 `scripts/plotting/q3/make_q3_figures.py`。脚本只读取冻结的 NPZ 与 JSON，不重新运行求解器；边界情景图仅绘制基准与高湿情景，并将 $C_a=0.03$ 标为无唯一终止时间的离散根分支局限。重新生成的汇总图和四张独立图已完成目视检查。

### A3：重新运行条件未满足

本次环境的 Python 运行时没有 SciPy，因而只完成 AST、JSON、NPZ、Excel、路径和图件静态核验，没有重新运行 Q3 主程序或验证程序。`q3_validation.json` 的验收结论来自压缩包交付材料；后续若环境补齐 SciPy，应按 README 命令重新运行并比较摘要。

### A4：Q3 依赖冻结 Q2 实现

`code/q3/q3_main.py` 动态加载 `code/q2/q2_main.py` 的几何、物性、有限体积和重构函数，并读取 `results/q2/q2_solution.npz` 做一致性检查。因此 Q3 不是完全独立的单文件程序；写作和复现说明应明确这一共享依赖。

## 写作前结论

基准 Q3 结果、表 5、`result3.xlsx` 和主要验证数字已经具备写作证据，可以开始基准情景的正文组织。正文应明确 $14400\,\mathrm{s}$ 后环境冻结假设、约 $57.17\,\mathrm h$ 的有效精度口径、连续事件与 $205800\,\mathrm s$ 规则采样点的区别，并将低湿根分支问题写入局限。绘图脚本已入库，但不应把文件路径或图件复现说明写成物理结论。
