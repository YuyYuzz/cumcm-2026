# 优秀论文证据化写作指南

## 一、跨论文共性

五篇样本共同显示，较强的数学建模论文写作不是“多写模型名”，而是让读者持续知道四件事：当前问题是什么、为什么采用此方法、证据表明什么、结论能回答题目到什么程度。

### 1. 论证链

推荐的最小链条为：

`题目目标 → 数据/物理困难 → 必要假设 → 模型或方法 → 求解/实验 → 结果 → 验证 → 题目答案与局限`

多问题论文应先定义共享对象和通用模型。后续每问只说明继承内容、新增困难和必要修改，不重复完整背景。

### 2. 段落职责

优先使用三类段落：

- **方法段**：困难是什么 → 为什么选择该方法 → 核心表达式/步骤 → 输出将供哪里使用。
- **结果段**：比较对象与条件 → 最重要结果 → 趋势或异常解释 → 对题目答案的意义。
- **验证段**：潜在误差来源 → 检查方法 → 观察到的证据 → 该证据能支持和不能支持的结论。

若一段同时承担背景、算法教程、结果和评价，应拆分。若相邻两段给出同一结论，应合并或删除重复。

### 3. 摘要

摘要应形成正文的可核查缩影：

1. 用极短背景界定总问题和目标；
2. 每问交代任务、核心方法、最重要结果或结论；
3. 必要时补一句验证或总体贡献；
4. 关键词覆盖问题对象和核心方法，不收入正文边缘工具。

控制算法名密度。读者需要知道“方法为何适合”，不需要在摘要中看到完整软件流水线。所有数字必须能在正文同口径位置回查。

### 4. 公式叙述

每个关键公式至少完成三次连接：

- **公式前**：说明它要表达的机制、约束或计算目标；
- **公式中**：符号、单位、定义域和边界条件一致；
- **公式后**：解释各项作用、实际含义、求解输出及适用条件。

标准算法公式只有在影响本文改动、参数或解释时才展开。否则引用方法并集中写本文如何使用，避免教科书式推导挤压核心论证。

### 5. 结果与证据

结果不等于图表复述。至少回答：

- 在什么条件下比较什么；
- 哪个趋势、差异或异常最重要；
- 这一现象由模型中的什么机制解释；
- 它如何回答当前问题；
- 是否存在适用边界或不确定性。

将客观输入、模型输出和作者解释分开措辞。使用“数据给出”“模型计算”“据此推测”等不同主语，避免把推断写成事实。

### 6. 图表作为写作节点

每张图表只承担一个主要论证任务，例如：说明数据结构、比较方案、解释机制、验证收敛、展示敏感性或汇总结论。

正文应有两次连接：图表前写目的，图表后写最重要发现及含义。图题或表题尽量包括对象、条件、指标和必要单位；不要只写“结果图”“变化图”。视觉样式由绘图技能处理，不从优秀论文复制配色或数据。

### 7. 验证与局限

验证必须对应误差来源：离散误差用收敛性，拟合遗漏用残差，参数不确定性用敏感性或区间，算法实现用已知真值回收，模型选择用简化/完整模型比较。

第二种算法与主算法共享数据和假设时，只能称交叉印证。局限应指出遗漏机制、失效条件和影响方向，避免“模型仍可进一步优化”之类空话。

## 二、从个别论文吸收什么

- A196：学习多问的共享模型链、章节承接和先化简后计算；不要复制其冗长算法步骤。
- B060：学习基准方法与完整方法的双路线，以及由机理解释异常点；不要把共享假设的两种方法写成独立验证。
- B157：优先学习数据流叙述和多维验证；按项目误差来源选取检查，不机械复制所有图。
- C023：学习现实目标如何变成损失与约束；把其区间重叠和文字矛盾作为一致性审计反例。
- C132：学习模型升级前解释新增困难；把准确率口径混乱和算法堆叠作为反例。

## 三、写作前证据表

写作前为目标章节建立最小证据表：

| 拟写结论 | 类型 | 证据文件/位置 | 可用口径 | 缺口 |
|---|---|---|---|---|
| 例：网格已收敛 | 模型验证 | `results/convergence.csv` | 最大相对误差 | 尚缺更细网格 |

没有证据的定量句不进入正文。正式引用只支持方法或事实，不支持本项目尚未算出的结果。

## 四、推荐的三遍流程

1. **结构遍**：只看标题、段落职责、问题间继承关系和图表任务。
2. **证据遍**：逐个核对公式定义、结果文件、图表、引用和数字口径。
3. **语言遍**：删除重复背景、算法教程、空泛评价和强于证据的措辞。

最后按项目 `docs/paper-quality-rubric.md` 评分。低于4分的维度不得仅靠润色措辞通过，必须补足相应结构或证据。
